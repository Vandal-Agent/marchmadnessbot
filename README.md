# MarchMadnessBot

Sports betting analysis and prediction bot.

## Current Features

- NCAA game prediction
- MLB watchlist generation
- Automatic game logging
- Automatic result grading
- Daily report generation

## Project Structure

- `app/` - Application code
- `data/` - Runtime data (not tracked)
- `logs/` - Runtime logs (not tracked)
